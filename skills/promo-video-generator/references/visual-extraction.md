# Visual Extraction

Use when working with image URLs or visually rich URLs. Extract only what helps the promo argument.

## Extract

- **Visual identity** — genre signals, world identity, motifs, palette, visual density
- **Shot language** — close-up vs wide, cinematic vs gameplay-first, clean vs noisy, premium vs raw
- **UI relationship** — show UI for proof / hide UI for beauty / mix intentionally
- **Promo texture** — hype montage / premium reveal / raw gameplay / calm beauty / feature-demo clarity

## Output format

Visual signals · Dominant mood · Recommended shot tone · UI usage recommendation · Risks · Promo transfer rule
