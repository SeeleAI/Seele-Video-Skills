# Messaging Framework

A promo video is an argument. Make claims, then show proof.

## Message layers

1. **Hook** — first promise, surprise, or tension
2. **Core value proposition** — what the player gets from the experience
3. **Selling points** (2–5) — e.g. unique combat, beautiful world, progression depth, social fun, strong character, high replayability
4. **Proof points** — evidence for each selling point:
   - gameplay depth → UI-on battle screenshot
   - art quality → UI-off beauty scene
   - progression → menu/system screenshot
   - world scale → environment landmark shot
   - character identity → target-focused character screenshot
5. **CTA** — one action: wishlist / play now / pre-register / join the test / follow for updates

## Rule

Every major claim must have evidence or be labeled as weakly supported.
