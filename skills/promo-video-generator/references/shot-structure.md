# Shot Structure

Choose the structure that fits the promo goal and duration.

## Structures

**10–15s** (social short, ad, teaser burst):
Hook → Core gameplay/visual proof → Key differentiator → CTA

**20–30s** (gameplay overview, feature update, mobile/store):
Hook → Core loop → Supporting feature → Emotional/visual payoff → CTA

**30–60s** (store trailer, launch trailer, feature demo):
World/fantasy hook → Core gameplay proof → System/progression proof → Feature variety montage → Strongest identity shot → CTA

## Rules

- Strongest proof early
- Clarity before excess beauty
- End with action or memory

## Segment format

For each segment: Name · Goal · Approx duration · Key visual proof · Copy direction · Asset source
