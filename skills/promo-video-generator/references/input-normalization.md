# Input Normalization

Normalize every request before planning. Do not start with shots — start with intent and evidence.

## Required fields

Product name · Promo type · Platform · Duration · Aspect ratio · Audience · Launch stage · Primary goal · Tone · Core promise · Selling points · Available assets · Unity screenshot availability

## Promo types

teaser · gameplay trailer · launch trailer · short ad · store trailer · feature highlight · update announcement · vertical social promo

## Evidence types

| Source | Provides |
|---|---|
| User text | Intent, priority, positioning |
| Text URLs | Official framing, feature detail, launch language |
| Image URLs | Visual direction, mood, composition style |
| Unity screenshots | Real gameplay / scene / UI proof |

## Normalized output structure

```
Product / Promo type / Goal / Audience / Platform / Duration / Ratio / Tone
Core promise / Selling points / Existing assets / Screenshot-capable scenes
Missing inputs / Open questions
```
