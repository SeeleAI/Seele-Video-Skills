# CTA Patterns

Choose CTA based on release stage. Keep it short, one action, no impossible CTA.

| CTA | Use when |
|---|---|
| Wishlist now | Pre-launch, store interest building |
| Play now | Live game, direct conversion |
| Pre-register now | Mobile upcoming launch |
| Join the beta | Alpha / beta / playtest |
| Follow for updates | Awareness stage, no conversion path yet |
