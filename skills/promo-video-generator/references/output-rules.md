# Output Rules

## Label categories

- **User Fact** · **Extracted Finding** · **Available Evidence** · **Assumption** · **Open Question** · **Missing Asset**

## Required sections

Every output: promo objective · audience · hook · core promise · selling points · recommended structure · storyboard or shot list · asset plan · CTA direction · assumptions · open questions.

If Unity screenshots are relevant: screenshot plan.
If video generation is relevant: generation task list.

## Rules

1. Do not make unsupported claims.
2. Tie selling points to evidence.
3. Do not request screenshots without storyboard purpose.
4. Match structure to duration and platform.
5. Keep CTA realistic.
6. If source materials are weak, say so.

## Final check

- Audience clear? · Message clear? · Each major claim has proof?
- Storyboard usable? · Screenshot plan actionable? · Missing assets visible?
- Next production step obvious?
