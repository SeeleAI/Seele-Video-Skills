# Workflow

## Steps

1. **Parse** — promo type, platform, duration, ratio, audience, tone, release stage, goal.
2. **Normalize** — merge user text / URLs / images / Unity capability into: Known / Unknown / Available evidence / Missing evidence.
3. **Extract message** — hook, core promise, selling points, proof points, CTA direction.
4. **Extract visual signals** — motifs, tone, framing style, UI visibility preference.
5. **Decide asset strategy** — what comes from: existing assets / reference URLs / Unity screenshots / video generation.
6. **Plan screenshots** — for each: purpose, claim supported, target, view_axis, show_ui.
7. **Choose shot structure** — match to duration, platform, goal, asset reality.
8. **Build storyboard** — each shot: timing, purpose, proof, source, text, transition.
9. **Build asset plan** — what exists / must capture / must generate / optional.
10. **Execute generation** — when the request is to produce video and segment specs are resolved, load `ai-model-calling` and call it in the same flow. Do not stop at a handoff.

## Quality bar

A good promo package: knows what it's selling · knows what proof exists · uses screenshots deliberately · uses generation deliberately · does not confuse beauty with evidence.
