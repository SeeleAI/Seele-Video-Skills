# Game Trailer

Build a trailer around the player fantasy, not a feature inventory.

## Inputs

- Game title, genre, platform, audience, release state, and CTA
- Approved gameplay/cinematic captures or a clearly labeled concept brief
- Duration and aspect ratio
- Verified claims, ratings, logos, music, and asset rights

## Workflow

1. Verify every public claim and label unavailable footage as a placeholder.
2. Choose one promise: what the player gets to feel or do.
3. Structure the cut: immediate hook → world/player fantasy → escalating gameplay → title/CTA.
4. Produce a timed shot list with source, framing, transition, caption, sound beat, and disclosure for every shot.
5. Keep generated concept footage visibly separated from captured gameplay unless the user has approved an explicit disclosure treatment.
6. Run factual, rights, platform, accessibility, and playback QA before delivery.

## Output

Return `brief.md`, `edit-timeline.csv`, `shot-list.csv`, `captions.srt`, `asset-ledger.csv`, `qa.md`, and model-ready prompts only for approved missing shots.

## Guardrails

- Never fabricate reviews, awards, release dates, platforms, gameplay systems, or multiplayer support.
- Do not present generated footage as actual gameplay.
- Do not use music, logos, characters, or footage without documented rights.
